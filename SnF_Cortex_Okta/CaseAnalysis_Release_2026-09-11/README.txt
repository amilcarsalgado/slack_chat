Case Analysis Tool - Quick Start 
================================= 
 
1. Copy BOTH files to the same folder on your machine: 
     CaseAnalysis_2026-09-11.exe 
     zscaler_root_ca.pem 
 
2. Double-click CaseAnalysis_2026-09-11.exe 
 
3. When prompted, sign in with your CIENA SSO credentials in the browser. 
 
Notes: 
  - Requires network access to Snowflake, VPN or office network. 
  - A file named combined_ca_bundle.pem will be created alongside the 
    exe on first run; this is normal and expected. 
  - No passwords are stored anywhere in this tool.
